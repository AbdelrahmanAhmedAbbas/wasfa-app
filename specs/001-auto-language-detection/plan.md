# Implementation Plan: Auto Language Detection

**Branch**: `001-auto-language-detection` | **Date**: 2026-03-14 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-auto-language-detection/spec.md`

## Summary

The app always displays in English regardless of the device's system language. The root cause is that `LanguageProvider.tsx` uses `Intl.DateTimeFormat().resolvedOptions().locale` which does not reliably read the device UI language on the Hermes JS engine. Additionally, the `setLanguage` function is a no-op, so user manual overrides are never saved.

The fix replaces the broken detection with `expo-localization`'s `getLocales()`, wires `setLanguage` to AsyncStorage for persistence, and adds a language toggle to the Profile screen.

### Step 2 — Fix LanguageProvider.tsx

**File**: `lib/i18n/LanguageProvider.tsx`

**Changes**:

1. Import `expo-localization` instead of `NativeModules`
2. Replace `detectDeviceLanguage()` with `expo-localization`'s `getLocales()[0].languageCode`
3. On mount: read AsyncStorage for a saved preference; if found, use it; else use device detection
4. Wire `setLanguage` to save to AsyncStorage and update state
5. On AppState foreground resume: re-run device detection ONLY if no manual preference is saved

**Key logic**:
```
INIT:
  savedLang = await AsyncStorage.getItem('@wasfa/language')
  if savedLang is 'en' or 'ar':
    use savedLang
  else:
    use getLocales()[0].languageCode → map 'ar*' → 'ar', else → 'en'
  setIsReady(true)

setLanguage(lang):
  await AsyncStorage.setItem('@wasfa/language', lang)
  setLanguageState(lang)

AppState foreground:
  savedLang = await AsyncStorage.getItem('@wasfa/language')
  if savedLang is null:
    re-detect from device and update state
  // if saved, leave as-is
```

**No flash guarantee**: `LanguageProvider` already returns `null` when `!isReady`. The async init (AsyncStorage read + locale read) completes before `isReady` is set to `true`, so the app never renders in the wrong language.

### Step 3 — Add Language Toggle to Profile Screen

**File**: `app/(tabs)/profile.tsx`

**Changes**:

Add a language settings row in the profile screen, using the existing translation keys (`t("language")`, `t("english")`, `t("arabic")`). The toggle is a two-option pill selector (EN | AR). Tapping a language calls `setLanguage(lang)`.

This replaces or sits alongside the "Coming Soon" placeholder section.

**Required context**: Add `setLanguage` and `language` to the destructured `useLanguage()` call.
